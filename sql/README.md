This directory contains 8 production-grade analytical SQL queries designed for data analysts, analytics engineers, and growth leaders. Every query answers a strategic business question using the dbt marts generated by RetentionIQ in PostgreSQL.

## Production Design Principles

1. **Anti-Leakage Guarantees:** Queries on experiments and survival strictly separate pre-treatment or landmark history from evaluation horizons.
2. **Right-Censoring Awareness:** Time-to-return queries (`02_cohort_retention_matrix.sql` and `07_retailrocket_category_retention.sql`) explicitly filter out unobservable observation windows to prevent artificial retention deflation.
3. **Divisor Protection:** All ratios and growth rates wrap denominators in `NULLIF(..., 0)` to guarantee zero division-by-zero runtime exceptions.
4. **Deterministic Sorting:** Window functions with ties (such as `NTILE(10)`) include unique primary keys in the `ORDER BY` clause to guarantee bit-for-bit reproducible deciles across executions.
5. **Index Awareness:** Aggregations leverage partition keys and index layouts on `customer_id`, `order_date`, and `visitor_id`.
